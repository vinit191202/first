🧑‍🎓 Student Management System (Python + Tkinter + MySQL)

A simple desktop-based Student Management System built using Python, Tkinter, and MySQL.
The application allows users to Add, Update, Delete, Search, and View student records in a MySQL database using a graphical interface.

📌 Features

Add new student records

Update existing records

Delete student records

Search students by:

Roll Number

Name

Contact

View all students in a scrollable table

Clean and simple Tkinter GUI

MySQL backend for persistent storage

🛠️ Technologies Used

Python 3

Tkinter (GUI)

MySQL (pymysql library)

ttk.Treeview (Data table)
